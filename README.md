# 아웃소싱 프로젝트 (13조)

## 👨‍🏫 프로젝트 소개
|구분|내용                                           |
|----|-----------------------------------------------|
|이름|noweat(나우잇)|
|기간|2025.02.28 ~ 2025.03.07 (8일)|
|팀원|김민재(팀장), 박성현, 박은지, 홍수경|
|설명|백엔드 기술만으로 간단한 배달 앱 구현|
|기능|회원가입/로그인, 가게, 메뉴, 주문, 리뷰|
|사용 기술|java, Spring MVC, Spring DATA JPA, MYSQL|

### 핵심 기능
- JWT 사용
- ArgumentResolver 사용
- 타인의 정보 조회 제한
- 메뉴 등록시 권한과 중복 확인

</br>

## 🧑‍🤝‍🧑 역할 분담
|팀원|역할                             |
|---|---------------------------------|
|김민재|회원가입/로그인, 주문, 리뷰 CRUD|
|박성현|유저 CRUD|
|박은지|가게 CRUD|
|홍수경|메뉴 CRUD|
